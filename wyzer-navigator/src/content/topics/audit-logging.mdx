---
name: Audit Logging
type: resource-linked
summary: >-
  Whether important system and access events are recorded so activity can be
  reviewed and investigated. Frameworks expect security-relevant events to be
  logged and monitored.
updated: 2026-09-04
cards:
  - framework: nist
    plain: >-
      Activity is expected to be logged and monitored so that anomalies and
      potential incidents can be detected.
    detail: >-
      NIST CSF 2.0 Detection (DE.CM) covers continuous monitoring of networks and
      systems to find adverse events.
    source: NIST CSF 2.0 · DE.CM
    sourceUrl: https://www.nist.gov/cyberframework
  - framework: soc2
    plain: >-
      Systems are expected to be monitored, and logs support detecting and
      responding to security events.
    detail: >-
      Maps to CC7.1 and CC7.2 (monitoring for anomalies and evaluating security
      events).
    source: SOC 2 TSC · CC7.1 / CC7.2
    sourceUrl: https://www.aicpa-cima.com/topic/audit-assurance/audit-and-assurance-greater-than-soc-2
  - framework: iso27001
    plain: >-
      Logs of user activities, exceptions, and security events are expected to be
      produced, kept, and reviewed.
    detail: >-
      Annex A controls A.8.15 (logging) and A.8.16 (monitoring activities) in
      ISO/IEC 27001:2022.
    source: ISO/IEC 27001:2022 · A.8.15 / A.8.16
    sourceUrl: https://www.iso.org/standard/27001
  - framework: hipaa
    plain: >-
      Systems holding health information must record and examine activity through
      audit controls.
    detail: >-
      HIPAA Security Rule audit-controls standard (45 CFR 164.312(b)).
    source: HIPAA Security Rule · 164.312(b)
    sourceUrl: https://www.hhs.gov/hipaa/for-professionals/security/index.html
  - framework: pci-dss
    plain: >-
      Access to system components and cardholder data must be logged and those
      logs actively reviewed.
    detail: >-
      PCI DSS v4.0 Requirement 10 covers logging and monitoring all access to
      system components and cardholder data.
    source: PCI DSS v4.0 · Requirement 10
    sourceUrl: https://www.pcisecuritystandards.org/
---

**In practice.** Turn on audit logging across your platforms, centralize the
logs somewhere tamper-resistant, and alert on the events that matter, such as
privileged actions and access to sensitive data.
