---
name: Card Data Retention
type: industry-only
summary: >-
  How long cardholder data may be stored. PCI DSS expects storage of card data to
  be minimized and kept only as long as there is a legitimate business need.
updated: 2026-09-04
cards:
  - framework: pci-dss
    plain: >-
      Keep stored cardholder data to a minimum, define how long it is retained and
      when it is disposed of, and never store sensitive authentication data (such
      as the full track or the security code) after authorization.
    detail: >-
      PCI DSS v4.0 Requirement 3.1-3.2 covers data-retention and disposal
      policies, and Requirement 3.3 prohibits storing sensitive authentication
      data after authorization.
    citations:
      - label: "PCI DSS v4.0 · Req. 3.1-3.3"
        url: https://www.pcisecuritystandards.org/
---

**In practice.** Do not store card data unless you truly need it. Never keep the
security code or full magnetic-stripe data after a payment is authorized, and
purge stored card data once it passes your defined retention window.
